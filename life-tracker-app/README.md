# 🌟 生活工作台

一个个人生活管理 PWA 应用，集成**减肥记录**、**心情记录**和**攒钱+花费记账**三大功能模块，支持离线使用，可安装到手机/桌面主屏幕。

## ✨ 功能特性

### ⚖️ 减肥记录
- 设置起始体重和目标体重，实时查看进度
- 体重趋势折线图（含目标线参考）
- 体重变化趋势标注（↑增/↓减/→持平）
- 历史记录管理

### 😊 心情记录
- 5 级心情快速选择（超棒/不错/一般/不太好/很差）
- 心情统计柱状图
- 月度心情日历热力图
- 心情日记列表

### 💰 攒钱 + 花费记账
- 收支双模式切换（攒钱/花费）
- 8 大分类选择（餐饮、购物、交通、工资等）
- 小金库余额实时计算
- 近 7 天收支柱状图
- 账单明细列表

### 📊 总览仪表盘
- 一站式查看所有核心数据
- 数据导出/导入（JSON 格式）
- 一键清空数据

## 📱 安装方法

### Android (Chrome)
1. 用 Chrome 浏览器打开应用页面
2. 点击浏览器菜单（右上角 ⋮）
3. 选择「添加到主屏幕」或「安装应用」

### iOS (Safari)
1. 用 Safari 打开应用页面
2. 点击底部分享按钮（⬆️）
3. 选择「添加到主屏幕」

### 桌面 (Chrome/Edge)
1. 用 Chrome 或 Edge 打开应用页面
2. 点击地址栏右侧的安装图标（⊕）
3. 或点击浏览器菜单 → 「安装此应用」

## 🚀 本地运行

```bash
cd life-tracker-app
python3 -m http.server 8090
```

然后浏览器打开 `http://localhost:8090`

## 🛠️ 技术栈

- **前端**：原生 HTML5 + CSS3 + Vanilla JavaScript（无框架依赖）
- **存储**：localStorage（数据完全本地化，隐私安全）
- **图表**：Canvas API 手绘（无第三方图表库）
- **可安装**：PWA（manifest.json + Service Worker）
- **离线支持**：Service Worker 缓存策略

## 🔒 隐私说明

所有数据存储在本地浏览器中，不会上传到任何服务器。清除浏览器数据将删除所有记录，建议定期使用「导出数据」功能备份。
